# Lab2-Sorting

Лабораторна робота №2 з дисципліни «Теорія алгоритмів» — логарифмічні алгоритми сортування.

- **Виконав:** Церковний О. Г., група АІ-254
- **Варіант:** 22
- **Вхідна послідовність:** `19, 75, 43, 31, 5, 66, 62, 34, 76`

## Структура репозиторію

| Файл | Опис |
|---|---|
| `merge_sort_iterative.py` | Ітеративне сортування злиттям (Лістинг 2.1) |
| `merge_sort_recursive.py` | Рекурсивне сортування злиттям (Лістинг 2.2) |
| `quick_sort.py` | Рекурсивне швидке сортування за схемою Хоара (Лістинг 2.3) |

Кожен файл підраховує кількість порівнянь (`comparisons`) та присвоювань (`assignments`); для рекурсивних версій також рахуються рекурсивні виклики.

## Запуск

Потрібен Python 3.8+. Зовнішні бібліотеки не потрібні.

```bash
python merge_sort_iterative.py
python merge_sort_recursive.py
python quick_sort.py
```

## Результати (варіант 22)

Відсортований масив: `[5, 19, 31, 34, 43, 62, 66, 75, 76]`
